# Simulador PNAE
Objetivo: Calcular o Repasse para uma escola do município de Osasco de acordo com o número de matrículas e verificar se ela é elegível para complementação municipal.
Como usar: O usuário pode mexer no número de matrículas de acordo com a modalidade, no número de dias letivos e pode mexer no fator de ajuste para ver quanto aproximadamente que a escola receberá em repasse de acordo com o número de matrículas.
Disclaimers: foi utilizado o Chat GPT para a realização desse projeto, mais especificamente para gerar o arquivo em HTML.
Exemplo de prompt utilizado: Transforme um arquivo xlsx em HTML mantendo as formulas, deixando o usuario mexer no numero de matriculas e no fator de ajuste. 
fonte: dados ficticios do INEP em relação a prefeitura de Osasco. (de acordo com a professora).
os dados representam os números de matricula nas escolas da prefeitura de Osasco descrevendo a partir do número de matriculas o repasse anual do número de matriculas
estrutura: colunas estão relacionadas a tipos de escola, número de matriculas para o usuario mexer e identificar a elegibilidade e inelegibilidade do repasse anual
participação do grupo: Aprendemos sobre tradução de dados do excel em arquivos HTML e organizar projetos no github.
