# Painel Censo
Objetivo: Verificar as caracteristicas das escolas de São Paulo em termos de dependência, tamanho, se possui água potável, se está ligada à energia elétrica e se possui coleta de lixo regular.
Como usar: O usuário pode escolher se visualizará em relação às escolas urbanas ou escolas rurais.
Disclaimers: foi utilizado o Chat GPT para a realização desse projeto, mais especificamente para gerar o arquivo em HTML.
Exemplo de prompt utilizado: Transforme um arquivo xlsx em HTML mantendo as formulas, o formato dos gráficos e colocando índices de números menores no início do dash que não ficariam bons em gráficos visuais, que foram ajustados manualmente. Não demos conta de transformar a coluna lixo em tabela dinâmica e pedimos para a IA transformar em gráficos.
fonte: dados reais do PNAE. os dados representam os tipos de escoola, com o usuário tendo a opção de escolher entre urbano e rural e verificar se as escolas possuem diferenças estruturais consideráveis, como coleta de lixo, agua, energia, se estão ativas ou inativas e etc.
estrutura: o usuario pode escolher entre urbano e rural, tanto índices quanto gráficos representam as características da escola do municipio de São Paulo, como esgoto, lixo, etc.
participação do grupo: Aprendemos sobre tradução de dados do excel em arquivos HTML e organizar projetos no github e usar IA para manipular dados que não conseguimos inserir na tabela dinâmica do excel.
