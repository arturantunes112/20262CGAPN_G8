# Painel Censo
Objetivo: Verificar as caracteristicas das escolas de São Paulo em termos de dependência, tamanho, se possui água potável, se está ligada à energia elétrica e se possui coleta de lixo regular.
Como usar: O usuário pode escolher se visualizará em relação às escolas urbanas ou escolas rurais.
